# Historical evidence

These documents are preserved for provenance, not loaded as current build instructions. Use root `PRODUCT.md`, `CONTEXT.md`, and `docs/architecture/README.md` instead. Historical statements such as "fixed," "do not reopen," old deadlines, package versions, and completed decision lists do not override current decisions.

| Location | Preserved material |
| --- | --- |
| `planning/` | Original proposals/PDFs, presearch, MVP PRD/handoff, old PRODUCT/CONTEXT, and the initial build-readiness plan |
| `gauntlet/` | Previous surfaces specification, prompts, and prototypes |
| `surface-decisions/` | Resolved decision tickets formerly in `.scratch/surfaces/` |
| `designs/` | Earlier design rounds, assessments, and imported canvases |
| `brainlift-example/` | Original example vault and writing guidance |

Original prose and relative paths are retained in historical files; some refer to their original locations. The table above provides the relocation map. Prototype folders retain their internal files together. Do not rewrite an old decision to make it appear that it was made with today's knowledge.

Imported HTML/captures under `designs/`, third-party material under root `references/`, and tool caches remain local and ignored by Git. Application packaging includes only `out/`, package metadata, and the repository license. Owned design-system assets remain separate until deliberately adopted.
