# Applied Research

<!-- impeccable:product-schema 1 -->

## Platform

web

The product uses web UI in Electron on macOS, Windows, and Linux. The design-system deliverable is a locally runnable web reference, not the production Electron app.

## Stack

The September 4 MVP PRD specifies React, Vite, and handwritten CSS for the product renderer. The standalone design-system reference uses HTML, CSS custom properties, and JavaScript so its visual and interaction contracts can be inspected without the production backend. This is a reversible artifact implementation choice, not a change to the product stack.

## Users

Builders learning an unfamiliar research domain in order to build in it. The beachhead is the Gauntlet AI cohort; expansion is open-source builders using coding agents.

## Product Purpose

Keep research reading, questions, original reactions, synthesis, and export connected. Output is a human-owned Playbook and a Context pack for coding agents.

## Positioning

AI supplies cited assistance and facts. Human notes, insights, and theses remain human-authored. Evidence, authorship, and verification status are separate concepts.

## Operating Context

Desktop, sustained reading of papers, selection-based Explain/Note/Counter/Idea, reaction collection, synthesis, and export. Local vault ownership. Current product requirements: docs/mvp-prd.md.

## Capabilities and Constraints

Core: paper-first entry, Reader, inline explanation, human reactions, Workbench, Playbook/Context pack, Settings. Map, calibration, finder, rabbit-hole sources, and stress-test have stretch scope as defined by the PRD. This design reference may demonstrate future patterns while labeling their scope. It does not call live AI, store API keys, or claim working source ingestion.

## Brand Commitments

Name: Applied Research. The user requests a new visual system informed by World Labs and the attached blue, engraved landscape image. This request supersedes earlier palette/image prohibitions for the new system. Preserve the old imports as historical evidence. The application should retain the clarity and authorship distinctions praised in the first teardown.

## Evidence on Hand

docs/designs/applied-research-design-case-study.md; independent assessments and screenshots in docs/designs/review-evidence; original canvases in docs/designs/Design System Canvas Setup; World Labs website and user-supplied screenshot. No user-study outcome or production performance claim has been established.

## Product Principles

- Preserve human authorship and the reasoning trail.
- Make sources inspectable and verification status explicit.
- Preserve reading position and unfinished work.
- Give useful orientation without unsolicited coaching.
- Treat activity as activity, never as measured mastery.

## Accessibility & Inclusion

Readable text contrast, keyboard-operable controls, explicit state and authorship semantics, reduced motion, and desktop reflow are design requirements. The reference does not establish full conformance for a future app.
