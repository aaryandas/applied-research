## Named desktop operations and lifetime

`SourceDesktopOperations` is constructed by production `src/main/index.ts` and owns a `SourceAdoption`. Preload exposes only the named operations in `src/contracts/source-desktop.ts`: activate a project, discover, acquire-and-save, cancel, open an original identity and generate a sourced path. Acquisition accepts an identity offered by trusted discovery or already retained in that project; it never accepts renderer canonical text or a renderer URL. Main parses responses and returns `saved` only after the local transaction completes. The returned edition ID comes from the acknowledgement, including replay of an older edition.

Project replacement, sign-out, native window close, renderer loss and navigation revoke pending source acceptance and file selection. Practical operations check the selected workspace and validate their exact immutable activity/attempt using the producer. Local human saves remain available without a signed-in account. The native dialog selects one bounded file; paths/bytes never cross the renderer bridge.

The Shell offers explicit supported tool choices rather than inferring a math tool from a topic. The producer tool adapter owns open/close/external sequencing; the host supplies bounds and load errors. Guidance stops and drafts flush before external handoff. No guest page text or fabricated native navigation-session identity is supplied to the companion.
