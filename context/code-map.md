Unit tests live beside their source. The MVP modules below own the implemented responsibilities.

`compose.sonar.yml` runs the local-only Sonar/PostgreSQL stack and official scanner with immutable images. `context/sonar-local.md` documents operation; `.env.sonar` is private, ignored local configuration.

## Source index adapter checkpoint

`src/backend/sourcing/index/adapter.ts` composes bounded indexing, deletion and hybrid retrieval. `writes.ts` validates acquired passages and authoritative tombstones; `retrieval.ts` builds identical scoped ANN/BM25 branches, validates exact canonical evidence and fuses ranks. `identity.ts`, `validation.ts`, `deadline.ts`, `transport.ts`, `results.ts`, `live-config.ts`, `resolve-transport.ts` and `types.ts` own generation/row identity, producer validation, operation deadlines, bounded HTTP, Oregon live URLs and mutually exclusive fixture/live transports. `index-acquired.ts` preflights write batches with a conservative finite-float JSON estimate (`-Number.MAX_VALUE` per dimension) before embedding spend; an oversize actual payload fails closed without a second embed. Paid write failures remain non-retryable. Adjacent public-boundary tests use synthetic vectors and provider responses. [Source index contract](source-index.md) and [sourced backend](sourced-backend.md) record live config, budgets and blocked production enablement. Live transport is composed only when `SOURCE_INDEX_LIVE=true` with backend-only credentials; default remains fixture-required / fail-closed.
