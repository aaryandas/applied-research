3.2 Attention
Select any passage to ask about it.

We call our particular attention "Scaled Dot-Product Attention". The input consists of queries and keys of dimension dk, and values of dimension dv. We compute the dot products of the query with all keys, divide each by √dk, and apply a softmax function to obtain the weights on the values.

Why divide by √dk and not dk?
If q and k have unit-variance components, their dot product has variance dk, so its standard deviation is √dk. Dividing by √dk restores unit variance; dividing by dk would collapse the logits toward zero and flatten the softmax. §3.2.1

The two most commonly used attention functions are additive attention, and dot-product (multiplicative) attention. While the two are similar in theoretical complexity, dot-product attention is much faster and more space-efficient in practice, since it can be implemented using highly optimized matrix multiplication code.

So the scale is a variance fix, not a magic constant. For my retrieval layer the analogue is normalizing embedding dot products before ranking — I've been skipping this. Vaswani 2017 · §3.2.1

While for small values of dk the two mechanisms perform similarly, additive attention outperforms dot product attention without scaling for larger values of dk. We suspect that for large values of dk, the dot products grow large in magnitude, pushing the softmax function into regions where it has extremely small gradients.

Layer normalization · §3
3 Layer normalization

A challenge in training deep networks is that the summed inputs to a layer change with the parameters of the layer below, which slows training. Batch normalization reduces this by normalizing the summed inputs to each neuron using statistics of a mini-batch.

We compute the layer normalization statistics over all the hidden units in the same layer: μ is the mean of the summed inputs and σ their standard deviation. All hidden units in a layer share the same normalization terms, but different training cases have different normalization terms.

Is this the same variance fix as the √dk scale?
Related but different. Scaling divides a dot product by its standard deviation before the softmax; layer normalization re-centers and rescales the summed inputs to a layer with per-layer statistics. Both keep activations in a range where gradients survive. Ba 2016 · §3

Attention is all you need · §3.2
3.2 Attention

We call our particular attention "Scaled Dot-Product Attention". The input consists of queries and keys of dimension dk, and values of dimension dv. We compute the dot products of the query with all keys, divide each by √dk, and apply a softmax function to obtain the weights on the values.

Why divide by √dk and not dk?
If q and k have unit-variance components, their dot product has variance dk, so its standard deviation is √dk. Dividing by √dk restores unit variance; dividing by dk would collapse the logits toward zero and flatten the softmax. §3.2.1
Ask follow-upNote in my words

The two most commonly used attention functions are additive attention, and dot-product (multiplicative) attention. While the two are similar in theoretical complexity, dot-product attention is much faster and more space-efficient in practice, since it can be implemented using highly optimized matrix multiplication code.

So the scale is a variance fix, not a magic constant. For my retrieval layer the analogue is normalizing embedding dot products before ranking — I've been skipping this. Vaswani 2017 · §3.2.1

While for small values of dk the two mechanisms perform similarly, additive attention outperforms dot product attention without scaling for larger values of dk. We suspect that for large values of dk, the dot products grow large in magnitude, pushing the softmax function into regions where it has extremely small gradients.

In practice, we compute the attention function on a set of queries simultaneously, packed together into a matrix Q. The keys and values are also packed together into matrices K and V. We compute the matrix of outputs as:

Attention(Q, K, V) = softmax(QKT√dk)V
(1)
