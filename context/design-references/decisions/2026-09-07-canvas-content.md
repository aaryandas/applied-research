# Canvas: content before chrome

The founder rejected the [generic insight node](2026-09-07-canvas-rejected-node.png): extra copy distracted from the actual insight, which was small and hard to see. Each type needs a distinctive visual identity, and the actual text must be immediately visible without zooming through useless text.

The revision removes generic node titles, repeated descriptive copy, per-node action footers, the Canvas introduction and column slogans. Actual content is the dominant 26px Newsreader text. Each node has one compact type/attribution marker with a distinct SVG symbol. Questions use a dashed rounded outline; experiments a cool, squared surface; human insights a warm surface and asymmetric corner; theses a double outline. The existing dark palette and rounded control language remain.

All recorded insights appear separately and retain exact human wording. Clicking a node opens its related work; dragging moves it without opening. Arrow keys move a focused node. Curved connections follow measured node bounds. The default is 100%; zoom has a 75% floor (19.5px effective content), and Reset view restores 100% rather than fitting the whole graph into unreadably small text. Horizontal scrolling reveals the remaining canvas.

This is a proposal for founder review, not final acceptance of the Canvas or full desktop product.
